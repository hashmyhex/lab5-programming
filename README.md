# Лабораторная работа № 5. Циклы

Решение задач на табуляцию и итерации, Python и C++.

## Файлы

- task1.py: таблица значений sin(x)
- task2.py: сумма, произведение и сумма квадратов чисел от 1 до N
- task3.py: числа Фибоначчи
- task4.py: разложение числа на простые множители
- task5.py: обработка цифр числа
- task6.py: проверка палиндрома
- task7.py: фигуры из символов
- examples.py: примеры break, continue, pass
- group7.py и group7.cpp: сумма ряда 1 + 1/2 + ... + 1/N
- sort_bubble.py: сортировка пузырьком
- search_binary.py: бинарный поиск

## Запуск

    python task1.py
    g++ -std=c++17 -o group7 group7.cpp
    ./group7
